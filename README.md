# Resolve Tester

This repository now includes a **Fusion-ready macro and expression baseline** so future programming work stays compatible with DaVinci Resolve Fusion workflows.

## What's included

- `fusion/COMPATIBILITY.md` — implementation rules for Fusion-safe scripting and expressions.
- `fusion/templates/MacroTemplate.setting` — starter macro template that demonstrates:
  - user controls and published macro variables,
  - expression-driven links between controls and tool parameters,
  - math expression patterns commonly used in Fusion.

Use these files as the canonical baseline before adding new macros or tools.
